    SD obsidian-speakerdeck-clipper

    一般

    保存先

    Vault に直接書き込みはノート・画像・PDF を Vault のフォルダへそのまま書き込みます。 ダウンロード + URI はファイルをダウンロードフォルダに落とし、ノートは obsidian:// で渡します。
    未選択です。
    obsidian:// でノートを開くときに使う Vault 名です。Obsidian 側の Vault 名と完全に一致させてください。 Enter で追加、先頭のものが既定になります。空のままなら Obsidian の既定 Vault が使われます。

      動作

      ポップアップのボタンを押したときの動作です。それ以外の動作はボタン横のメニューから選べます。
      Vault に直接書き込んだあと、obsidian://open でノートを開きます。
      URI が長すぎる場合は自動で clipboard=true に切り替え、本文をクリップボード経由で渡します。
      URI の長さ制限で本文が渡らなかったときのバックアップになります。
      保存と同時に、生成した Markdown 全文をクリップボードへ入れます。

      詳細

      テンプレートをすべて消して、初期状態のテンプレート 1 個に戻します。
      設定・テンプレート・プロパティ型をまとめて JSON に書き出します。
      現在の設定をすべて置き換えます。

      解析

      PDF のテキストレイヤーから十分な文字数が取れなかったページだけ、画像として認識にかけます。
      抽出できた文字数がこれ未満のページを OCR に回します。
      認識に使う学習済みデータです。言語を絞るほど速く、精度も安定します。
      各ページをこの幅で描画してから OCR と画像書き出しに使います。大きいほど精度が上がり、遅く・重くなります。
      0 で全ページ。動作確認で数ページだけ試したいときに使います。

      出力

      画像は各ページを WebP で書き出して ![[...]] で貼ります。 PDF のページ指定は ![[note.pdf#page=1]] を使うためファイルは 1 個で済みますが、 埋め込みごとに PDF ビューアが開きます。
      WebP の圧縮品質（0.1〜1.0）。下げるとファイルサイズが小さくなります。
      折りたたみコールアウトは全行が > で始まるため、空行があってもトグルから中身がこぼれません。 <details> は空行で HTML ブロックが終わる仕様を避けるため、空行を潰して <pre> に入れます。
      「PDF のページ指定」で埋め込む場合は必須です。

      プロパティ

      Vault 内の .obsidian/types.json を読み込むと、Obsidian 側と同じ型定義になります。 このフォルダは多くの OS で既定では隠しフォルダです。
      types.json として書き出します。Vault の .obsidian に置けば Obsidian 側でも同じ型になります。
      どのテンプレートからも使われていないプロパティ型を消します。

      すべてのプロパティ

      型を変えるとアイコンが変わり、フロントマターへの書き方（リスト・数値・真偽値・日付）も変わります。 既定値はテンプレートでプロパティを追加したときに自動で入る値です。

      変数とフィルタ

      変数

      テンプレートのノート名・保存先・プロパティ・本文で {{変数名}} として使えます。クリックでコピーできます。

      フィルタ

      {{変数|フィルタ}} のように | でつないで値を加工します。複数つなげられます。 例: {{author|split:", "|wikilink|join}}
