# obsidian-speakerdeck-clipper

Speaker Deck のスライドを文字起こしして Obsidian に保存する Chrome 拡張機能（Manifest V3）です。
生成 AI は使わず、PDF 取得から OCR・Markdown 生成まですべてブラウザローカルで処理します。外部 API への送信はありません。

保存先・プロパティ・ノート本文は**テンプレート**として設定画面で自由に組み立てられます。
詳しい仕様・アーキテクチャ・メンテナンス方針は [docs/](docs/) を参照してください。

---

## セットアップ

```bash
git clone <this repo>
cd obsidian-speakerdeck-clipper
./setup-libs.sh          # PDF.js / Tesseract.js / 学習済みデータを lib/ に配置（約 25MB）
```

続いて Chrome に読み込みます。

1. `chrome://extensions` を開く
2. 右上の「デベロッパー モード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」→ このディレクトリを選択

> `setup-libs.sh` が何を配置するか、学習済みデータの版を変える方法は
> [docs/maintenance.md](docs/maintenance.md) を参照してください。

## 使い方

1. Speaker Deck のスライドページ（`https://speakerdeck.com/{user}/{slug}`）を開く
2. ツールバーの拡張機能アイコンをクリック
3. ノート名・プロパティ・保存先を確認（値はその場で編集できます）
4. **「スライドを解析」** → PDF を取得してページごとに文字起こし
5. 本文を確認して **「Obsidian に追加」**

> **長いスライドの場合**: ポップアップは画面外をクリックすると閉じ、処理も中断されます。
> ヘッダーの ⧉ ボタンでタブとして開き直すと、OCR が長時間かかるスライドでも中断されません。

### ポップアップ

保存に必要な操作だけを置いています。設定項目は一切ありません。

| 要素 | 説明 |
| --- | --- |
| テンプレート選択 | 使うテンプレートを切り替える。URL 条件に一致するものが自動で選ばれます |
| ノート名 | 作成するノート名。PDF と画像のファイル名もこれに揃えます |
| プロパティ | フロントマターになる項目。左のアイコンが型、右が値。値はその場で編集できます |
| ノート本文 | 生成された Markdown。送出前に直接編集できます |
| 保存先フォルダ | ノートを置く Vault 内のパス |
| 保存ボタン | 解析前は「スライドを解析」、解析後は既定の保存動作。▾ から別の保存方法も選べます |
| ⚙ | 設定画面（`settings.html`）を開く |

### 設定画面

拡張機能アイコン → ⚙、または `chrome://extensions` の「拡張機能のオプション」から開きます。

| セクション | 内容 |
| --- | --- |
| **一般** | 保存方法（Vault へ直接書き込み / ダウンロード + URI）、Vault フォルダと Vault 名、保存動作、設定の書き出し・読み込み |
| **解析** | OCR の有無・判定しきい値・言語・レンダリング幅・最大ページ数 |
| **出力** | スライドの埋め込み方法、画像品質、抽出テキストの表示形式、PDF の保存 |
| **プロパティ** | プロパティ名ごとの型と既定値。Obsidian の `types.json` を読み書きできます |
| **変数とフィルタ** | テンプレートで使える変数・フィルタの一覧（クリックでコピー） |
| **テンプレート** | ノート名・保存先・プロパティ・本文フォーマットの組。複数作って URL で自動選択できます |

各項目の詳細は [docs/features.md](docs/features.md) を参照してください。
